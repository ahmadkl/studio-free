# استوديو الذكاء

تطبيق عربي للهاتف: توليد صور، وتحويل قصة إلى فيديو، ودردشة، ومكتبة محلية. يعمل كصفحة ويب قابلة للتثبيت (PWA) ويمكن تحويله إلى APK تلقائيًا عبر GitHub Actions.

## ما المجاني فعلًا وما ليس مجانيًا

| الميزة | التكلفة | ملاحظة |
|---|---|---|
| صور عبر Pollinations | مجاني بلا حساب | حدّ تقريبي صورة كل 15 ثانية، وشروطه تتغير |
| صور عبر AI Horde | مجاني | مجتمعي، بطيء، وهذا المسار تجريبي |
| صور عبر Cloudflare Worker خاص بك | مجاني ضمن حصة يومية | يلزم حساب Cloudflare (ملف `cloudflare-worker/worker.js`) |
| تحليل القصة والدردشة | مجاني بلا حساب عبر Pollinations، أو بحساب Puter | قد يتغيّر الوصول دون إشعار |
| تركيب الفيديو من الصور | مجاني بالكامل | يعمل على جهازك، بزمن حقيقي |
| فيديو ذكاء اصطناعي حقيقي (Wan، Kling، Seedance…) | **غير مجاني** | يخصم من رصيد حسابك في Puter. «وضع التجربة» داخل التطبيق لا يخصم |

## النشر من الهاتف

1. أنشئ مستودعًا جديدًا على GitHub وارفع إليه كل محتويات هذا المجلد كما هي (بما فيها `.github` و`www`).
2. **نسخة الويب:** من إعدادات المستودع افتح Pages، واختر Source ثم GitHub Actions. بعد أول تشغيل يظهر رابط الموقع. افتحه في Chrome واختر «إضافة إلى الشاشة الرئيسية».
3. **نسخة APK:** من تبويب Actions افتح «Build Android APK» ثم Run workflow. بعد نحو 5 إلى 10 دقائق افتح Releases ثم الإصدار `latest` وحمّل `ai-studio.apk` وثبّته (يلزم السماح بالتثبيت من مصدر غير معروف).

## كيف يعمل فيديو القصة

1. تكتب القصة، فيقسّمها النموذج إلى مشاهد مع وصف ثابت لكل شخصية.
2. تراجع المشاهد وتعدّلها، ثم تولّد صورة لكل مشهد.
3. يركّب التطبيق الفيديو على جهازك: حركة كاميرا، وانتقالات، وترجمة عربية، وموسيقى اختيارية.
4. «مدّد القصة» يضيف مشاهد تكمل الحكاية.

## حدود يجب معرفتها

- التسجيل بزمن حقيقي: فيديو مدته دقيقتان يحتاج دقيقتين تقريبًا، ويجب إبقاء التطبيق مفتوحًا والشاشة تعمل.
- الفيديو الطويل (حتى 10 دقائق) ممكن بدمج مشاهد كثيرة، لكن توليد صورها بالخدمة المجانية بطيء.
- ثبات الشخصيات تقريبي (وصف ثابت وبذرة مشتركة)، وليس مطابقة تامة.
- «تحريك صورة» حركة كاميرا فقط، وليس حركة شخصيات. الحركة الحقيقية تحتاج وضع الفيديو الذكي (مدفوع).
- لا يوجد صوت تعليق في الفيديو المركّب، فقط موسيقى اختيارية.
- تسجيل الدخول إلى Puter قد لا يفتح داخل APK. سجّل من نسخة المتصفح مرة واحدة إن حدث ذلك.

## مفتاحك وبياناتك

كل الإعدادات والصور والفيديوهات تُحفظ على جهازك فقط (التخزين المحلي وIndexedDB). التطبيق يرسل الأوصاف إلى المزوّد الذي تختاره لتوليد الصورة أو الردّ.
